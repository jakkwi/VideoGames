# Writing docs

- English, short sentences, tables for comparisons.
- Never use long dashes (em dash or en dash). Use commas, colons, parentheses or a plain hyphen. A hook checks new lines.
- A decision that is expensive to reverse gets an ADR in `docs/adr/NNNN-title.md` (Status, Context, Decision, Consequences).
